# @pdfcommons/workers

In-browser PDF tools for [PDF Commons](https://www.pdfcommons.com). MIT.

Merge, split, rotate, reorder, delete pages, JPEG/PNG to PDF, and basic compress run on bytes you pass in. This package does not open a network connection.

```bash
node --experimental-strip-types --test src/*.test.ts
```

Password protect, unlock, and page rasterizing are not in this version. PDF to Word is a server job in the private app, not in this package.
